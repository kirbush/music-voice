# Как приложение работает с данными

- Когда включён слушатель, звук с микрофона обрабатывается на устройстве. Для распознавания команды фрагмент аудио передаётся в отдельный процесс приложения. Команды и фоновый звук не сохраняются в файлы.
- При настройке под голос приложение сохраняет акустические признаки трёх повторений ключевой фразы в собственном каталоге Android. Это помогает детектору и не используется для аутентификации. В настройках можно перезаписать образцы. Очистка данных приложения удаляет образцы, настройки и загруженные модели.
- Служба специальных возможностей отслеживает открытие Spotify и штатных мультимедиа для запуска слушателя. Тексты и результаты читаются в Spotify при обработке команды. Приложение хранит до 32 недавно встреченных исполнителей локально, чтобы уточнять запросы.
- Автозапуск также реагирует на загрузку Android, обновление приложения, пробуждение экрана и начало проигрывания мультимедиа. Из аудиособытий Android используется признак воспроизведения. Само аудио других приложений для этого не захватывается.
- Распознанный поисковый запрос открывается в Spotify. Сетевые запросы Spotify обрабатывает сам установленный клиент. Разрешение на интернет в «Музыке голосом» используется для загрузки моделей с Hugging Face. Каждый файл проверяется по размеру и SHA-256.

Отключить фоновой микрофон можно кнопкой «Выключить прослушивание» или действием в уведомлении Android. Разрешение на выбор результата отзывается в разделе специальных возможностей.
