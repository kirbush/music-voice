# Музыка голосом

Голосовой поиск музыки в Spotify на головных устройствах Voyah с Android 11. После фразы активации приложение распознаёт название и исполнителя локально. Оно открывает поиск в установленном Spotify и запускает трек при однозначном совпадении.

## Первый запуск

1. Установите APK для ARM64 и войдите в Spotify на устройстве.
2. Откройте «Музыка голосом» и скачайте модели. Доступны Whisper Base и FUTO‑74. С уже скачанными моделями активации для FUTO‑74 понадобится ещё 81,8 МБ.
3. Разрешите доступ к микрофону и включите службу «Музыка голосом» в специальных возможностях Android.
4. Нажмите «Включить прослушивание». Скажите «Алиса», дождитесь сигнала и назовите трек. Фраза и движок меняются в настройках.

Чтобы включить автовыбор без ADB, откройте **Настроить автовыбор Spotify** и включите «Музыка голосом» в системном списке служб. Если приложение вместо этого показывает **Как включить автовыбор Spotify**, прошивка не предоставляет доступного экрана. На такой сборке ГУ для подключения нужен системный или уже привилегированный инструмент, поддерживающий настройку сторонних служб. Разрешения на микрофон и установка APK через Obtainium сами по себе службу не включают.

С версии 0.13 слушатель запускается после загрузки Android, обновления приложения, включения экрана или запуска мультимедиа. Для этого нужны ранее выданный доступ к микрофону и включённая служба специальных возможностей. Кнопка «Выключить» приостанавливает и дальнейший автозапуск до ручного включения. Если прошивка ограничивает автоматический доступ к микрофону, приложение показывает уведомление для ручного включения.

Поисковая команда сама открывает установленный Spotify, в том числе если его недавно закрыли. При холодном запуске у клиента есть отдельное время на открытие экрана поиска.

При голосовом запросе можно указать тип результата.

- «Включи группу Depeche Mode» и «Включи исполнителя Depeche Mode» открывают карточку артиста. Трек можно выбрать на экране.
- «Включи трек Enjoy the Silence» и «Включи песню Enjoy the Silence» ищут по названию. Имя артиста можно добавить для уточнения.
- Если сказать только «Включи группу» или «Включи трек», приложение попросит название и подаст второй сигнал. Ключевую фразу повторять не нужно.
- Без явного типа приложение сначала проверяет совпадения среди треков. Если они не подходят, оно может открыть карточку по точному имени артиста.
- «Включи трек Numb группы Linkin Park» содержит два отдельных поля. Приложение сверяет с выдачей и название, и исполнителя. Если результат остаётся непонятным или неоднозначным, оно один раз попросит уточнить запрос.

При запросе только по названию и одноимённых записях разных артистов приложение выбирает первый трек, если первое и следующее точные совпадения указывают на одного исполнителя. При равнозначных результатах можно выбрать трек вручную.

Проверено на Voyah с Android 11 и Spotify 9.2.0.2053. Автовыбор зависит от экрана поиска Spotify и аудиомаршрутов прошивки. [Работа приложения и данные](docs/PRIVACY.md)

## Сборка

Понадобятся Git, curl, Python 3.12+, JDK 17 и Android SDK. Укажите корень SDK через `ANDROID_HOME` или `--sdk`. Установите компоненты через SDK Manager или командой.

```sh
sdkmanager --install "platforms;android-30" "build-tools;34.0.0" "ndk;27.2.12479018" "cmake;3.22.1"
python voice/build.py --test
python voice/build.py
```

Готовый APK появится в `.build/MusicVoice-arm64.apk`. Сборщик сверяет SHA-256 зависимостей и проверяет подпись, целостность и ABI. Веса скачиваются на устройстве при первом запуске.

Сборка по умолчанию подписывается локальным тестовым ключом. Чтобы обновить уже установленный APK, нужен тот же ключ подписи. Для подписанного релиза передайте `--keystore`, `--key-alias` и `--store-pass-file`. Опция `--unsigned` выдаёт выровненный APK для последующей подписи.

## Код

| Путь | Что внутри |
| --- | --- |
| `voice/src` | Экран настроек, микрофон, обработка команд и выбор результата в Spotify |
| `voice/native` | JNI-адаптер whisper.cpp для FUTO‑74 |
| `voice/bench` | Тесты разбора команд, ранжирования, правил интерфейса Spotify, холодного запуска и загрузчика моделей |
| `.github/workflows/build.yml` | Сборка APK и проверка исходников в GitHub Actions |
